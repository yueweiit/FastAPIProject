# 入库与库存模块

## 功能

商品每批到货独立建档，保存原始数量、剩余数量、采购金额、单价、整批物流/其他成本、单件总成本、到货/发货时间、钉钉单号及创建人。提供搜索分页、编辑、删除和嵌入图片的 Excel 导出。依据：[routers/batches.py](../../../routers/batches.py)。

钉钉单号是留档字段，没有钉钉审批API调用。批次无store_id，普通读取共享；admin/operator可跨创建人编辑历史批次（含已售），强制留日志。已售数量保留，金额/数量更正通过追溯成本差额处理；operator删除仍限自己创建且未消耗、无补差的批次。原创建人和库存归属不转移。

## 成本与一致性

有total_amount时按总金额÷数量计算采购单价，旧请求仅传purchase_price时换算总金额。首次入库或从未消耗的直接更正按采购单价＋整批费用÷数量计算unit_cost；已售成本重述保留其基准单价，以冻结构成和差额得到有效成本。采购和物流不能重复计入。

编辑先锁行、当前读调整层并核对销售明细，新余量=新数量−原已售数；删除仍要求未消耗。FIFO/撤销锁序保留，仍按商品共享扣库，不按店铺选择批次。库存店铺继续由创建人当前绑定推导。

字段精度由 DECIMAL(12,4) 保存；算法没有在 _calc_unit_cost 中显式 quantize，展示舍入不能替代持久化规则。依据：[models.py](../../../models.py)、[fifo.py](../../../services/fifo.py)。
