# 入库与库存模块

新增独立“库存”菜单：共享库存总览、安全库存预警、按天/按商品/横向日期表和出入库来源明细。复用当前批次、FIFO及已有数量更正日志，仅SELECT，无新表、迁移或历史回填。管理员有全量日结，其他绑定账号仅有本店出库，隐藏全量期初/调整/期末；历史按当前有效单据重算，不能恢复撤销前已删除的销售明细。口径及限制统一见[库存查看流程](workflow.md#库存查看与每日进出)，代码入口为[inventory.py](../../../routers/inventory.py)、[inventory_activity.py](../../../services/inventory_activity.py)、[inventory-workspace.js](../../../static/inventory-workspace.js)。

## 功能

库存内增加“库存盘点与跌价”：截止日成本/准备、逐批入库日期/天数/归属分摊，以及人工实盘、盘点时账面数、差异及不可覆盖历史版本。仅新增盘点对照表，不自动调整库存或财务金额。角色/历史日期限制、导出及快照语义见[盘点流程](workflow.md#人工盘点对照)。

跌价归属在库存总览/盘点页按批次手工维护，入库可先保存为待分配，数量/成本编辑不再要求同时选择归属。管理时至少选择一家，可多选均分；保留从入库日更正/从今天起生效两种模式。新待分配批次不沿用创建人店铺，跌价照算、店铺分摊待核对；历史无日规则记录仍按原兼容规则读取，不批量回填。归属不设销售额度、不改变共享FIFO。详见[归属流程](workflow.md#批次跌价归属)。

库存页支持Excel导出：总览导出当前查询全部库存，每日视图导出整月汇总/明细，横向日期表可导出同布局；按商品查看仅导出所选商品。沿用页面权限和待核对空值，范围/上限见[库存导出](api.md#库存导出)。

商品每批到货独立建档，保存原始数量、剩余数量、采购金额、单价、整批物流/其他成本、单件总成本、到货/发货时间、钉钉单号及创建人。提供搜索分页、编辑、强制删除（软作废）和嵌入图片的 Excel 导出。依据：[routers/batches.py](../../../routers/batches.py)。

钉钉单号是留档字段，没有钉钉审批API调用。批次无store_id，普通读取共享；admin/operator可跨创建人编辑历史批次（含已售），强制留日志。已售数量保留，金额/数量更正通过追溯成本差额处理。所有批次统一通过“强制删除”软作废，admin/operator均可跨创建人填写原因操作：保留批次、销售、成本、快照及旧月度版本，不再作为可用库存，新销售不能扣此批次。旧垃圾桶及物理删除逻辑停用，旧DELETE接口返回410。关联销售成本与利润标记待核对，需另行处理原销售归属。原创建人和库存归属不转移。

## 成本与一致性

有total_amount时按总金额÷数量计算采购单价，旧请求仅传purchase_price时换算总金额。首次入库或从未消耗的直接更正按采购单价＋整批费用÷数量计算unit_cost；已售成本重述保留其基准单价，以冻结构成和差额得到有效成本。采购和物流不能重复计入。

编辑先锁行、当前读调整层并核对销售明细，新余量=新数量−原已售数；作废在批次和调整层行锁内校验版本，与日志同事务提交。FIFO/撤销锁序保留，仍按商品共享扣库，不按店铺选择批次。跌价归属由batch_impairment_stores手工选择；已有日规则优先；无历史且未指定时才沿用创建人当前绑定。FIFO不采用该归属作销售限制。

字段精度由 DECIMAL(12,4) 保存；算法没有在 _calc_unit_cost 中显式 quantize，展示舍入不能替代持久化规则。依据：[models.py](../../../models.py)、[fifo.py](../../../services/fifo.py)。
