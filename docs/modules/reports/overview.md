# 报表与自动快照模块

## 功能

支持月度商品销量/当前库存、指定截止日存货跌价准备、自动月末快照、单店月度损益及人工项目保存、产品线毛利和 Excel 财务附件。损益读取 OA PostgreSQL 的办公费用、薪资和分摊管理费用。

财务导出保留原有顺序：07存货、09单店损益、10跨店汇总、12产品线，末尾追加07存货SKU汇总；管理员五张、非管理员四张（省略跨店损益汇总且财务附件范围受绑定店铺限制）。独立存货查询/导出仍为全局范围，不应混同。依据：[routers/reports.py](../../../routers/reports.py)。

## 主要规则与职责

- 按真实批次及FIFO明细回放持有期间；入库当天0天，销售当天先计提再转销，每天只增加当日准备。
- 新品日增0.5%，稳健日增1%；按规则历史和当天安全库存分层，单层最多90%，受保护时保留原准备。
- 明细/SKU包含全部已到货批次，按各批成本及日期计算再加总；售完余额0，但本月总计提和转销可非0。
- 期初+本月总计提−本月转销=期末准备；账面=现存成本−期末准备，保留现存库存本月计提作区分。
- 查询/导出不补建快照；上月从同一回放取得。快照仍保留旧算法和不覆盖策略。
- 全局分配共享安全库存后按现有范围输出。历史时序/数量异常金额及不完整合计留空；跨店/缺失归属的损益转销待核对，未猜测或修改源数据。
- 损益取期间总计提并用转销抵减营业成本；产品线采用同一明细调整。人工科目和现有成本分类保留。
- 商品/销售/成本/规则或当前店铺绑定变化会影响动态结果，历史完整性及生产仍待验证。

批次页面/Excel23列，SKU页面18列/API与Excel19字段；完整血缘见[字段说明](inventory-impairment-fields.md)。业务、算法和本地验证见[持有期间变更](../../development/2026-10-15-holding-period-impairment.md)，财务目标保留于[FINANCIAL_REPORTING_TARGET.md](../../../FINANCIAL_REPORTING_TARGET.md)。
