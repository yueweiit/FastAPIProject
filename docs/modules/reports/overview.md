# 报表与自动快照模块

## 功能

支持月度商品销量/当前库存、指定截止日存货跌价准备、自动月末快照、单店月度损益及人工项目保存、产品线毛利和 Excel 财务附件。损益读取 OA PostgreSQL 的办公费用、薪资和分摊管理费用。

财务导出管理员有四张工作表：07存货、09单店损益、10跨店汇总、12产品线；非管理员仅三张，省略跨店汇总且财务附件范围受绑定店铺限制。独立存货查询/导出仍为全局范围，不应混同。依据：[routers/reports.py](../../../routers/reports.py)。

## 主要规则与职责

- 存货按截止日前入库数量减已确认销售成本明细重建；不能用当前剩余数替代历史库存。
- 商品类型和安全库存采用生效历史；稳健商品每日1%，新品每日0.5%，累计上限90%。
- 现存库存累计准备与本月计提分列；本月计提仅统计报告日仍在库商品本月新增的准备，账面价值较上月变化单列并包含库存数量变化。
- 上月比较使用冻结快照的数量/单价结合当前可用规则历史重算；快照记录不覆盖，但显示比较值不等于直接读取 snapshot.book_value。
- 本月新增批次上月比较基准为0；历史批次缺少上月快照时显示待核实，页面和 Excel 均保留未知差额。
- 损益自动项来自销售、FIFO 分解、跌价、OA；人工项与备注保存于 JSON，公式项由系统计算。
- 产品线需有效店铺映射和来源 SKU 归属，缺失/歧义进入“未分配产品线”，不能按商品名称猜测。
- 月末快照由应用启动/每小时检查或报表补建，没有人工结账页面或公开会计期间 API。

详细公式、期间与快照边界见[流程](workflow.md)。财务目标保留于 [FINANCIAL_REPORTING_TARGET.md](../../../FINANCIAL_REPORTING_TARGET.md)，其中每日比例、比较差额方向和冻结描述与当前实现存在差异，需要财务确认。
