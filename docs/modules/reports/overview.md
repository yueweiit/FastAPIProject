# 报表与自动快照模块

## 功能

支持月度商品销量/当前库存、指定截止日存货跌价准备、自动月末快照、单店月度损益及人工项目保存、产品线毛利和 Excel 财务附件。损益读取 OA PostgreSQL 的办公费用、薪资和分摊管理费用。

财务导出保留原有顺序：07存货、09单店损益、10跨店汇总、12产品线，末尾追加07存货SKU汇总；管理员五张、非管理员四张（省略跨店损益汇总且财务附件范围受绑定店铺限制）。独立存货查询/导出仍为全局范围，不应混同。依据：[routers/reports.py](../../../routers/reports.py)。

## 主要规则与职责

- 存货按销售日期及FIFO批次明细重建每一天的库存，逐日累计当天跌价金额；不能用报告日余量代替历史每天库存。
- 明细及SKU汇总均包含截止日前全部批次，已售完旧批保留售前累计。各批按自身入库成本、日期和规则独立计算，汇总加总数量/金额。
- 当天累计比例采用规则历史；稳健日增1%，新品日增0.5%，每部分比例上限90%，逐日金额合计不封顶。
- 财务自定义账面价值=原始入库成本−逐日累计跌价，可为负；本月金额为当月各天金额之和，包含当月已售商品售前金额。
- 上月比较用相同每日公式重算，不读取/补建准备余额快照；自动快照和店铺损益保持原余额口径。
- 本月新增批次上月比较基准为0；现有历史批次按保存流水计算，缺失的真实采购/销售/规则仍待验证，不凭空补造。
- 损益自动项来自销售、FIFO 分解、跌价、OA；人工项与备注保存于 JSON，公式项由系统计算。
- 产品线需有效店铺映射和来源 SKU 归属，缺失/歧义进入“未分配产品线”，不能按商品名称猜测。
- 月末快照由应用启动/每小时检查生成；07查询/导出不再补建，没有人工结账页面或公开会计期间API。

详细公式、期间与快照边界见[流程](workflow.md)。财务目标保留于 [FINANCIAL_REPORTING_TARGET.md](../../../FINANCIAL_REPORTING_TARGET.md)，原始模板目标与历史确认保留，新口径以2026-10-12最终确认及当前代码为准；其他财务目标仍需按任务核实。

批次页面全部 20 列和 SKU 汇总 15 列的数据库来源、接口字段、公式、Excel 列位和可复算示例见[存货明细逐字段说明](inventory-impairment-fields.md)。
