# 销售与文件导入模块

## 功能与角色

销售页提供指定店铺的独立人民币结算补录；订单详情按产品名识别组件并FIFO扣库，保留批次成本明细；导入旧三列 CSV 或 TikTok“订单详情”CSV/XLSX/XLSM；保存结算原始行、组合 SKU 组件分摊、历史汇率和导入批次；提供待确认原因筛选/导出、原记录重试与商品组合确认、文件撤销、销售分页与人民币月度汇总。销售台账支持按当前月份/商品筛选导出全部匹配记录，保留店铺权限、独立财务事件和未知金额空白，详见[导出流程](workflow.md#销售台账导出)。

写入/撤销仅 admin/operator；非管理员读取敏感数据按当前绑定店铺。operator 可撤销同店其他人的文件，并非只允许撤销本人文件。管理员文件导入必须明确选择有效店铺，运营自动归入当前绑定店铺且不能越店；新导入固化店铺，历史空归属不自动回填。手工销售仍有独立店铺选择。依据：[routers/sales.py](../../../routers/sales.py) 的 _resolve_import_store/import_sales_file。

## 核心业务规则

- FIFO 按商品在全局可用批次中取最早 arrived_at/id，行锁后复查库存；总成本保存于 sales，分批数量/成本保存于 sale_cost_details。
- 导入后台账/详情/导出自动按实际FIFO明细拆分采购、头程、尾程、其他入库成本及本行订单总成本；出库商品跌价单独参考列示，不重复影响成本或毛利。组合订单、分位尾差、全局安全库存和异常空值见[成本流程](workflow.md#出库成本拆分与跌价参考)。
- 订单详情按“产品名”识别本地商品，缺该列时读“商品名称”；支持A*4、A+B及组件合并。全半角规范化后精确匹配，库存订单重名、缺失或无法识别进入待确认，不回退到SKU映射。退款/调整保留可靠商品归属但不出入库，识别不到仍作为独立结算；组合退款不猜测金额份额。来源SKU ID仅展示/筛选，平台预映射不再是导入前提。
- 文件内格式/重复订单等错误阻止整体导入；商品未映射或库存不足可以保存为待确认，不部分扣减一整行组合商品。
- 同一个平台订单可有多个结算事件，source_key 使用事件字段哈希；不等于完整退款库存处理。
- 外币收入/费用通过结算行保存的汇率换算人民币，库存成本视作人民币。sales 原始 profit 不能直接替代 profit_cny。
- 撤销按原成本明细恢复原批次库存，删除该文件产生的销售/分摊/结算行，保留导入批次审计状态。

依据：[fifo.py](../../../services/fifo.py)、[exchange_rates.py](../../../services/exchange_rates.py) 和销售路由。实际流程、失败边界及待确认处理详见[workflow.md](workflow.md)。
