01 建立和核对商品资料

入口：商品管理。列表和图册已合并，可在同一页面切换；先查是否已有相同 SKU，再新增。商品名称仍参与订单详情识别。

  1. 在商品资料区输入 SKU、名称或规格并搜索，确认是否已建档。列表和图册共用搜索、资料筛选、分页和勾选结果；同一 SKU 不要重复建档。
  2. 点击“新增商品”，在侧栏填写 SKU、产品名称；“规格/型号”和图片按需要填写、上传。SKU 应保持稳定，名称尽量唯一。规格可以留空，填写时规范化后最多 255 个字符。
  3. 在“核算设置”中按已确认规则选择“跌价计提类型”和安全库存。只有“稳健商品”可以填写正数安全库存；“新品”和“不跌价商品”安全库存应为 0。
  4. 点击“保存”。成功后搜索核对 SKU、名称、规格和图片；如需核对类型或安全库存，打开“编辑商品”并展开“核算设置”。商品列表不再展示库存数量、库存价值和最近入库信息。
  5. 历史规格为空的商品显示空白；可用“缺少规格”筛选定位，通过“编辑商品”填写或继续留空保存。系统不会猜测或自动回填规格。类型或安全库存变化会影响后续跌价计算，先由业务负责人确认。
字段录入要求
SKU唯一标识；含前导零时保持文本，例如 00123。
产品名称订单文件“产品名”应与本地名称对应；重名可能造成待确认。
规格/型号选填，可以留空，最多 255 字符；例如“蓝色 / M”“银色 / 500 mL”。换行统一转为空格；规格描述商品，不替代 SKU。
跌价计提类型位于“核算设置”；稳健商品／新品／不跌价商品，不得凭操作人员习惯随意选择。
安全库存非负整数；它是现有跌价规则中的保护数量，不是新入库数量。
产品图片可选；支持系统认可的常见图片格式，原文件不超过 5 MiB。

完成标准：能在列表或图册查询到正确商品资料。点击商品行或卡片的“查看库存”，按该商品精确进入库存页，查看安全库存、库存数量、成本和最近入库。商品建档不增加库存，收货仍需“入库管理”；商品删除不作为更正收货或销售的手段。

02 批量新增商品

入口：商品管理 → 批量导入。适用于一次建立多条新商品资料，列表与图册共用此入口。

  1. 点击“下载模板”，按模板填写 SKU、商品名称、规格/型号、商品类型、安全库存五列。保持首行为表头，规格列位于商品名称后。
  2. SKU 列设为文本，保留前导零；规格/型号选填，类型使用模板支持的值。兼容没有规格列的旧四列模板；历史商品导出的空规格可继续留空。新品和不跌价商品的安全库存填 0。
  3. 选择 .xlsx 文件，点击“校验预览”。检查新增、跳过、错误数量和原始行号。
  4. 有错误时下载校验清单，修改原文件并重新预览；不要绕过错误直接提交。
  5. 全部待导入行校验通过后点击“确认导入”，完成后下载导入结果，并搜索抽查商品。
检查项当前规则
文件与规模.xlsx；最多 2000 条数据，上传上限 5 MB。
已有 SKU跳过，不覆盖已有商品资料；跳过行也需要字段合法。
公式与额外列五个导入字段不接受公式；图片、库存、金额、日期等额外列不作为入库。
隐藏行仍会读取，提交前清理不需要的隐藏数据。
预览有效期15 分钟；换文件、数据变化或预览过期后重新校验。
网络超时先查询商品是否已新增，再重新预览；不要凭超时认定整批未保存。

完成标准：预览错误已解决、结果清单已保存、新增 SKU 可查询。此功能只新增资料；已有 SKU 校验后跳过，不会通过重导来更新其规格或其他资料，也不导入历史库存。

商品 Excel 导出与旧文件兼容

“导出所选商品”导出跨页勾选的商品；“导出全部商品”导出全部商品，不受当前搜索和资料筛选限制。需要导出某一组时，先逐页核对并勾选；单条导出位于商品“更多”菜单。

商品导出继续保留图片、商品类型、安全库存、库存数量、库存价值和日期列，规格/型号位于名称后。历史空规格导出为空；重新导入时可继续留空。额外库存列不会转换为入库；修改导出文件再导入也不会覆盖已有 SKU。规格出现 [U+XXXX] 批注时，表示历史内容含不支持的字符，请核对原值后通过编辑修正。

03 收货核对与新批次入库

入口：入库管理 → 新批次入库。仓库先确认实物，录入人员再按已核对的采购及费用单据登记。

  1. 核对收货单与实物：商品 SKU、合格收货数量、实际到仓日期。对短少、破损或错货先登记差异，数量依据经确认的收货结果填写。
  2. 选择“产品 SKU”。填写数量及“总金额”，这里的总金额是整批采购金额，采购单价由总金额除以数量自动计算。
  3. 分别填写整批头程运费、尾程派送费、其他成本及对应钉钉单号。成本以人民币核算，外币单据先取得财务确认的人民币金额。
  4. 区分“头程发货时间”和“入库时间”。入库日期应是实际到仓日期；历史销售不能使用销售日之后才到货的库存。
  5. 检查系统显示的单件成本后点击“入库”。成功后在批次列表查到批次号，核对商品、数量、金额和入库时间。
  6. 转到“库存”检查商品余量，再按下一页要求设置跌价归属。
示例项目金额或结果
数量与采购金额100 件；采购总金额 1000 元；采购单价 10 元
物流与其他成本头程 120 元＋尾程 60 元＋其他 20 元
单件到仓成本10＋（120＋60＋20）÷100＝12 元
该批初始库存成本100×12＝1200 元

不要把整批费用填成每件费用，也不要将同笔费用同时计入采购总金额与其他成本。费用未知时向采购／财务核实，不将猜测的 0 当作已确认成本。提交超时先查批次，避免重复入库。

04 设置批次跌价归属

入口：库存 → 库存总览 → 跌价归属；也可从入库批次列表“修改归属”进入。按业务确认的承担店铺逐批维护。

  1. 找到商品，点击“跌价归属”，核对要处理的批次号和入库日期。
  2. 点击“设置归属”，至少选择一家店铺。选择多店时，系统按现行规则均分跌价金额。
  3. 核对生效范围，再点击“保存归属”。成功后刷新查看所选店铺。
生效范围适用情况及影响
从入库日起更正用于原始归属有误；历史动态查询会按新归属重算，已保存旧月度版本保留。
从今天起生效用于从当前日期变更承担店铺；此前费用保留，剩余准备转入新归属。

新入库可以暂待分配，但待分配不会停止全局跌价计算；有相关金额时店铺分摊会待核对，应在交接前处理。归属不限制店铺销售，也不改变库存数量和采购成本。历史范围更正须与财务确认影响月份。

05 准备销售订单文件

运营执行。先保留平台原文件，再检查用于导入的副本；本页说明现有“订单详情”导入格式。

检查项具体要求
文件类型支持 .xlsx、.xlsm 和 .csv；Excel 读取名称为“订单详情”的工作表。
九个必要表头结算日期、结算单 ID、付款 ID、状态、货币、交易类型、订单ID/调整单ID、SKU ID、数量。
商品识别字段补齐“产品名”，使用本地商品名称；只有缺少该列时才读取“商品名称”。保留列中的实际值。
业务金额与日期保留订单创建日期、净商品销售额、结算总金额，以及原始退款、折扣、运费等明细依据。必要表头齐全不代表金额完整。
表格内容检查实际导入的工作表与行；截图、其他工作表或仅显示在旁边的文字不会被读取。
店铺范围一批操作对应已确认的店铺；不要把不同店铺文件混合后导入一个店铺。

组合与倍数怎样填写

产品名示例来源数量应扣本地库存
示例逗猫棒3逗猫棒 3 件
示例逗猫棒*42逗猫棒 8 件
示例逗猫棒+示例猫抓板2两种商品各 2 件
示例逗猫棒*2+示例猫抓板3逗猫棒 6 件、猫抓板 3 件

组合表达式用“+”连接商品，用“*”表示每来源单位的倍数。同一行任一组件无法识别或库存不足，整行待确认，不会只扣一部分组件。

导入前最后检查

  1. 对照本地商品名称排除重名、错字和缺失商品；不要依赖已隐藏的旧平台 SKU 映射入口解决新订单识别。
  2. 确认销售日期以前已有真实到货。若当前库存充足但销售日可用库存不足，应追查真实单据日期。
  3. 确认订单、退款、调整、赔付的类型与金额符号；不擅改原始日期、数量或金额来绕过校验。

旧版无表头 CSV“SKU,日期,数量”仍保留兼容，但不等同于完整平台结算文件。常规经营对账优先采用保留金额、币种和日期的订单详情。

06 导入销售并处理待确认

入口：销售记录。上传后先确认保存结果，再处理待确认记录，最后检查库存变化。

  1. 核对“导入店铺”，点击“导入订单详情”选择文件。上传期间不要重复点击或重复提交。
  2. 等待“确认保存结果”完成。记录结算行、销售扣库存、重复跳过和待确认数量；处理中达到 100% 不等于已经提交成功。
  3. 按文件业务日期查询结果：商品销售优先使用订单创建日期；退款、运费调整等独立结算优先使用结算日期。查询月份不会改变导入归月。
  4. 到“导入历史”核对文件、店铺、时间及状态；可用“查看导入结果”回看该次保存结果。断线或超时先检查历史和台账，结果不明时交管理员核查。
  1. 按待确认原因、订单或文件筛选。检查销售日库存、产品名、组件及订单冲突。
  2. 商品不明确时用单条“确认商品”选择本地商品与每来源单位倍数；只作用于这一行。库存不足则核对真实到货与已发生出库。
  3. 修正原因后用“重新处理”或批量处理；当前筛选批量处理单次最多 200 条，超出时缩小范围。
  4. 检查成功、仍待确认和跳过数量，并回看原导入历史。直接重传原文件通常会去重，不能代替待确认处理。

完成标准：每条待确认记录已处理，或已列入异常交接清单。重试仍按原销售日及当前剩余库存校验，不会用晚到库存，也不会重新排列其他已售 FIFO。

07 销售核对与手工结算补录

销售台账用于检查导入结果；页面上的“手工结算补录”用于独立人民币金额记录。两者的库存效果不同。

核对人民币销售台账

  1. 选择月份，必要时按商品或 SKU 搜索。月度统计覆盖全部筛选记录，“本页合计”仅对应当前分页。
  2. 检查实际出库件数、人民币收入、费用和成本。组合按组件显示，来源套数和来源整行金额可能重复展示，不可再直接求和。
  3. 需要追查成本时打开“计算明细”，核对实际 FIFO 批次、出库数量和各成本分项。
  4. 使用“显示字段”“固定字段”和横向滚动查看完整列。金额待核对时保留异常，不把空白当作 0。
  1. 只有确需补录独立结算时才使用本表；先查原文件和订单，确认没有重复入账。
  2. 填写店铺、结算日期、订单号／调整单号、交易类型，并按来源填写 SKU ID、产品名、来源数量和人民币金额。
  3. 普通记录费用＝净商品销售额−结算总金额；赔付按结算总金额计收入。按原始凭据核对正负号后保存。
  4. 保存后查询对应月份和导入历史。若提示已保存但列表刷新失败，仅刷新列表，不再提交一遍。
操作库存结果
正常商品订单文件导入并确认按识别组件和销售日 FIFO 扣库存。
手工结算补录不关联本地商品，不扣库存，不生成成本或跌价。
退款、纯金额调整、赔付作为结算事件处理，不自动恢复或扣减库存。

退回实物须先收货、清点并交业务负责人确认处理方式；当前退款金额记录不能代替退货入库。非实物业务和初始化扣减分类由授权维护处理，一线人员不要自行改成普通销售或新入库。

08 查看库存与追查每日变化

入口：库存 → 库存总览／每日进出。查询时先看清商品范围、期间和当前账号权限。

  1. 从商品资料点击“查看库存”时，系统保留该商品的精确筛选，并在搜索框显示 SKU。也可在“商品名称／SKU”输入关键字：点选候选精确查询，直接输入后查询为模糊匹配。
  2. 库存总览集中显示安全库存、当前共享库存、库存成本金额、最近入库与预警。财务账面价值还要扣减跌价准备，不能直接用此成本替代。
  3. 切换“库存总览”和“每日进出”会保留未改动的商品筛选。选择月份和查看方式，按天、按商品或横向日期表核对入库、出库及调整；点击数量查看来源明细。需要换商品时重新选择或修改搜索并查询，清空后查询可解除原筛选。
  4. 发现差异时记录商品、日期、批次、订单和来源单号，核对是否有补单、数量更正、作废或导入撤销。
  5. 导出前先执行查询。库存导出使用当前查询的商品范围，覆盖全部匹配结果；每日进出按所选整月导出，并保留当前商品筛选，按商品模式仅导出所选商品。切换视图不会扩大原有精确筛选的导出范围。

数量勾稽：期末＝期初＋入库−出库＋调整。月汇总不能把每天期末余额相加。

权限差异：管理员可看全量日结；运营／查看者只能看授权入库及本店出库，全局期初、调整、期末可能留空。共享库存不能用单店出库自行倒推。

历史限制：此处按当前有效单据及已有更正记录重算。撤销销售导入后原出库明细不再存在，因此不能把它当成更正、撤销前的完整不可变流水。

09 录入实盘与处理盘点差异

入口：库存 → 库存盘点与跌价 → 录入实盘。保存的是盘点对照记录，不会自动进行盘盈盘亏调整。

  1. 盘点前核对当天入库、销售及更正单据是否齐全。系统日期按自然日日末核算，日内盘点要记录盘点时点并协调当天单据。
  2. 选择商品和截止／盘点日期，查看截止日账面库存。运营仅可录今天的共享库存；历史日期请管理员处理。
  3. 点击“录入实盘”，输入实数并写备注。0 表示实盘为零；空白表示未盘点，不能混用。
  4. 核对差异＝实盘数−盘点时账面数，然后点击“保存盘点”。保存后打开“盘点记录”核对版本与数量。
  5. 出现差异先复点，再查漏录、重复入库、销售待确认、日期错误及实际破损或丢失。记录原因，交负责人确认处理方案。
  6. 若提示账面变化或保存冲突，保留填写内容，关闭后刷新并重新核对；不要为了成功提交直接改数字。
情形处理要求
实盘大于账面正差异，先核查是否漏记入库或错误出库。
实盘小于账面负差异，先核查是否漏记销售、重复入库或实物损耗。
保存后又补单或更正历史差异保留；如系统提示需复核，核对后追加新版记录。

实盘数不参与系统库存成本、跌价和账面价值计算。不要修改原入库批次数量来强行抹平盘点差异；真实原单错误与盘盈盘亏是不同业务。

10 更正批次与撤销错误导入

先识别错误来源和影响范围，再选择入口。涉及已经发生销售、历史月份或财务凭证时，与负责人及财务共同处理。

错误情形处理入口关键影响
原入库资料、数量或金额错误入库管理 → 编辑核对原始凭据；数量不能低于已出库数。
跌价承担店铺错误库存 → 跌价归属确认从入库日起更正或从今天起生效。
整份销售文件导错销售记录 → 导入历史 → 撤销删除该次导入关联销售／结算并恢复实际扣减量。
批次本身应停用批次列表 → 强制删除实为软作废；需原因，可能影响历史财务核对。
仅存在盘点差异库存盘点与跌价登记差异并追查，保存盘点不自动平账。

批次更正步骤

  1. 搜索正确批次，记录原值、凭据、改动理由及受影响销售。打开“编辑”，修改经确认的字段。
  2. 核对已出库数。新剩余数＝更正后入库数−原已出库数，不会把已售数量重新加回。
  3. 已售批次数量或金额更正依赖财务增强；原 FIFO 单价保留，财务差额可追溯原销售月。若提示功能未启用，交管理员处理。
  4. 若出现版本冲突，取消编辑、刷新并核对最新值后重新打开；成功后核对列表、库存及必要的财务影响。

销售导入撤销步骤

  1. 在导入历史核对文件名、店铺、导入时间、销售数及待确认数，确认是整份文件确需撤销。
  2. 记录原因及已导出／已交接的报表，按内部授权后点击撤销并阅读确认提示。
  3. 成功后确认导入状态已撤销，库存仅恢复该导入实际 FIFO 扣减的数量。纯金额文件恢复库存为 0。
  4. 需要重导时先修正来源再导入，重新核对待确认及报表；若已被费用或结算分类引用而拒绝撤销，交财务处理更正凭证。

“强制删除”不是常规撤销销售或平账工具。作废不会删除旧销售成本，原剩余数量将退出可用库存；相关历史利润可能转为待核对。旧月度版本不会自动改写。
